# GitHub Copilot の設定とユーザー インターフェイスの機能を確認する

Visual Studio Code は、開発者向けのシームレスかつカスタマイズ可能な GitHub Copilot 環境として機能します。 この演習では、GitHub Copilot の設定を確認し、Visual Studio Code の GitHub Copilot ユーザー インターフェイスについて見ていきます。

この演習の完了に要する時間は約 **25** 分です。

> **重要**:この演習を完了するには、自分の GitHub アカウントと GitHub Copilot サブスクリプションを用意する必要があります。 GitHub アカウントをお持ちでない場合は、無料の個人用アカウントに<a href="https://github.com/" target="_blank">サインアップ</a>し、GitHub Copilot Free プランを使用して演習を完了できます。 ラボ環境内から GitHub Copilot Pro、GitHub Copilot Pro+、GitHub Copilot Business、または GitHub Copilot Enterprise サブスクリプションにアクセスできる場合は、既存の GitHub Copilot サブスクリプションを使用してこの演習を完了できます。

## 開始する前に

ラボ環境には次のものが必要です。

- Git 2.48 以降
- .NET または Python のいずれか:

    - **.NET SDK 9.0** 以降と、**C# 開発キット**拡張機能をインストールした Visual Studio Code。
    - **Python 3.10** 以降と、**Python** 拡張機能をインストールした Visual Studio Code

- GitHub Copilot が有効になっている GitHub アカウントへのアクセス。

この演習のラボ環境としてローカル PC を使用している場合:

- ローカル PC をラボ環境として構成する方法については、ブラウザーで次のリンクを開いてください: <a href="https://go.microsoft.com/fwlink/?linkid=2320147" target="_blank">ラボ環境のリソースを構成する</a>。

- Visual Studio Code で GitHub Copilot サブスクリプションを有効にする方法については、ブラウザーで次のリンクを開いてください: <a href="https://go.microsoft.com/fwlink/?linkid=2320158" target="_blank">Visual Studio Code で GitHub Copilot を有効にする</a>。

この演習に、ホストされたラボ環境をお使いの場合:

- Visual Studio Code で GitHub Copilot サブスクリプションを有効にする方法については、ブラウザーのサイト ナビゲーション バーにで次の URL を貼り付けてください: <a href="https://go.microsoft.com/fwlink/?linkid=2320158" target="_blank">Visual Studio Code で GitHub Copilot を有効にする</a>。

- パッケージのダウンロードと復元のソースとして公式の NuGet.org リポジトリを使用するように .NET SDK を確実に構成するには、次の手順を実行します。

    コマンド ターミナルを開き、次のコマンドを実行します。

    ```bash

    dotnet nuget add source https://api.nuget.org/v3/index.json -n nuget.org

    ```

- Python 用にホストされたラボ環境を構成するには、次の手順に従います。

    1. ホスト環境にインストールされている Python のバージョンを確認するには、次のコマンドを実行します。

        ```bash
        python --version
        ```

        必要に応じて、次の URL にある手順を使用して Visual Studio Code で Python を構成します: <a href="https://code.visualstudio.com/docs/python/python-tutorial" target="_blank">VS Code での Python の概要</a>。

    1. Visual Studio Code の [拡張機能] ビューを使用して Python 拡張機能をインストールします。

## 演習のシナリオ

あなたは地域コミュニティの IT 部署で働く開発者です。 公共図書館を支えるバックエンド システムが火災で失われました。 システムが置き換えられるまで、チームは図書館スタッフが業務を管理できるようにするための一時的なソリューションを開発する必要があります。 チームは、開発プロセスをスピードアップするために GitHub Copilot を選びました。

この演習には、次のタスクが含まれています。

1. Visual Studio Code で GitHub Copilot の設定を確認する。
1. Visual Studio Code で GitHub Copilot ユーザー インターフェイスを確認する。

## Visual Studio Code で GitHub Copilot の設定を確認する

GitHub Copilot の設定は、GitHub アカウントと Visual Studio Code 環境に分かれています。 Visual Studio Code では、設定を使用して GitHub Copilot の動作を構成できます。 VS Code 1.116 以降、GitHub Copilot は組み込みの拡張機能となり、GitHub Copilot の機能を使用するために個別の拡張機能をインストールする必要がなくなりました。 GitHub アカウントでは、設定を使用して GitHub Copilot サブスクリプションを管理し、プロンプトと提案の保持を構成し、パブリック コードに一致する提案を許可またはブロックすることができます。

> **注**: このセクションで説明する GitHub Copilot の設定は、Visual Studio Code 環境に固有です。 GitHub Codespaces や JetBrains IDE などの他の環境で GitHub Copilot を使用する場合は、それらの環境に固有の他の設定が存在する可能性があります。 Visual Studio Code の設定エディターでは、Copilot の設定が、コード編集、チャット、エージェント、インライン チャットの設定など、複数のカテゴリに分類されます。

### Visual Studio Code で GitHub Copilot を有効または無効にする

プランをアクティブにすると、Visual Studio Code の GitHub Copilot は既定で有効になります。 ただし、必要に応じて GitHub Copilot 機能を一時的に無効にし、準備ができたら再度有効にすることができます。

以下の手順に従って、演習のこのセクションを完了します。

1. Visual Studio Code の新しいインスタンスを開きます。

1. 下部のステータス バーで、GitHub Copilot アイコンを選択します。

    Copilot 状態メニューが開き、インライン候補や次の編集候補 (NES) を有効または無効にする機能など、GitHub Copilot の機能を管理するためのオプションが表示されます。

1. Copilot の状態メニューには、**[インライン候補]** および **[次の編集候補]** を有効または無効にするオプションが含まれていることに注意してください。

    インライン候補は、グローバルに無効にすることも、現在のファイルの言語に対して無効にすることもできます。 また、**[スヌーズ]** ボタンを使用してインライン候補を 5 分間隔で一時的に停止し、**[スヌーズのキャンセル]** を選択して再開することもできます。

1. チャット メニューを開くには、タイトル バーの [チャット] ボタンの右側にある [その他のアクション] ドロップダウンを選択します。

     チャット メニューには、チャット ビュー、クイック チャット、インライン チャットの各インターフェイスを開くオプションと、それらの各インターフェイスの設定を管理するためのオプションが含まれています。

1. チャット メニューで **[インライン候補の構成]** を選択します。

1. [インライン候補の構成] メニューには、**[インライン候補を無効にする]** オプションがあることに注意してください。

1. Visual Studio Code の [拡張機能] ビューを開くには、左側のメニュー バーで [拡張機能] アイコンを選択します。

1. [拡張機能] ビューで、検索バーに「**GitHub Copilot Chat**」と入力します。

1. GitHub Copilot Chat 設定メニューを開くには、GitHub Copilot Chat 拡張機能の歯車アイコンを選択します。

1. [AI 機能を有効にする] オプションと [AI 機能を無効にする] オプションに注意してください。

GitHub Copilot Chat 設定メニューには、特定の言語に対して GitHub Copilot 機能を有効または無効にするオプションが含まれています。 たとえば、ドキュメントで作業しているときに候補が不要な場合は、Markdown ファイルに対して GitHub Copilot を無効にすることができます。

有効化/無効化オプションをテストする場合は、無効化オプションを選択できます。 ただし、この演習を続行する前に、必ず GitHub Copilot を再度有効にしてください。

### GitHub Copilot Chat 拡張機能の設定を調べる

GitHub Copilot in Visual Studio Code をアクティブにすると、既定の設定が自動的に構成されます。 設定は [拡張機能] ラベルの下にまとめられており、GitHub Copilot Chat の設定が含まれています。 Visual Studio Code の設定タブを使用して、GitHub Copilot の設定をカスタマイズできます。

以下の手順に従って、演習のこのセクションを完了します。

1. Visual Studio Code の上部のメニュー バーで、チャット メニュー (タイトル バーの [チャット] ボタンの横にあります) を開きます。

    チャット メニューには、**[コード補完の構成]** オプションが含まれています。これは、GitHub Copilot に関連付けられている **[設定の編集]** を行うオプションを提供します。

1. チャット メニューで **[コード補完の構成]** を選択し、**[設定の編集]** を選択します。

1. 少し時間を取って、GitHub Copilot 設定がどのような構成かを確認しましょう。

    設定エディターの左側には、設定が、拡張機能のセクションなど、セクションごとに整理されて表示されていることに注意してください。 拡張機能セクションには、GitHub Copilot Chat 拡張機能が含まれています。 画面の右側には、選択したセクションの設定が表示されます (セクションが選択されていない場合は、すべての設定が表示されます)。 設定エディターの上部にある検索バーを使用して、キーワードで設定をフィルター処理できます。

1. [拡張機能] ラベルの下にある **[GitHub Copilot Chat]** を選択します。

    これで、設定の一覧がフィルター処理されて GitHub Copilot Chat の設定のみが表示されることに注意してください。

    GitHub Copilot Chat 拡張機能には使用できる設定が多数あり、定期的に更新されます。 GitHub Copilot Chat 拡張機能には、プレビューおよび実験的な設定も含まれており、変更されたり、廃止されたりする可能性があります。 プレビューおよび実験的な設定は一覧の最後に表示され、"**プレビュー**" または "**実験的**" というタグが付いています。

1. 少し時間を取って、GitHub Copilot Chat の設定を確認しましょう。

    このトレーニングの間は、既定の設定のままにすることをお勧めします。 そうすることで、演習に取り組む際に期待どおりの経験が得られるようになります。 トレーニングが完了したら、これらの設定を試して、エクスペリエンスをカスタマイズできます。

1. 設定エディターの上部にある検索バーに、「**GitHub Copilot Enable**」と入力します。

    これで、指定した言語に対して GitHub Copilot 入力候補を有効または無効にするために使用できる設定が表示されます。

1. 言語の一覧で、**[markdown]** を選択します。

    Markdown の既定値は **false** に設定されています。 これは、Markdown ファイルに対して GitHub Copilot 入力候補が無効になっていることを意味します。

1. Markdown ファイルに対して GitHub Copilot を有効にするには、**[項目の編集]** (鉛筆アイコン) を選択し、**[false]** を選択して、値を **[true]** に変更してから **[OK]** を選択します。

    GitHub Copilot を使用して Markdown ファイルを作成または更新できるようになりました。 たとえば、GitHub Copilot でプロジェクトのドキュメントを作成しているときに、コード補完の提案を生成できます。

1. Visual Studio Code の設定エディターを閉じます。

## Visual Studio Code で GitHub Copilot ユーザー インターフェイスを確認する

Visual Studio Code により、GitHub Copilot の AI 機能を開発環境にシームレスに統合できます。

GitHub Copilot の機能は次のカテゴリに分類されます。

- エージェント: エージェントは、コーディング タスクを完了するために自律的に動作する AI アシスタントです。 大まかな目標を与えると、エージェントはその目標を複数のステップに分割し、プロジェクト全体のファイルを編集し、コマンドを実行し、問題が発生した場合は自己修正を行います。 エージェントは、ローカル、バックグラウンド、またはクラウドで実行できます。

- 自然言語チャット: Visual Studio Code は GitHub Copilot と連携して、チャット ビュー、クイック チャット、インライン チャットなど、複数のチャット インターフェイスを提供します。 チャット ビューでは、3 つのモード (Ask、Plan、Agent) がサポートされており、会話中にこれらを切り替えることができます。

- インライン候補: GitHub Copilot では、入力時に 2 種類のインライン候補が提供されます。 ゴースト テキスト候補は、現在のカーソル位置に淡色表示のコード候補を提供します。 次の編集候補 (NES) は、既に行っている変更に基づいて、次の編集の場所と内容の両方を予測します。

- スマート アクション:GitHub Copilot では、スマート アクションを使用して一般的なタスクを自動化し、プロンプトの繰り返し作成を排除しています。

GitHub Copilot の生産性機能には簡単にアクセスできます。また、コーディング エクスペリエンスを中断することなくワークフローにシームレスに適合します。

### チャット ビューの機能を確認する

Visual Studio Code のチャット ビューには、GitHub Copilot と対話するための包括的なインターフェイスが用意されています。 チャット ビューは、Ask、Plan、Agent の各モードをサポートする統合エクスペリエンスです。そのため、同じ会話内で、質問、タスクの計画、エージェントの実行のすべてを切り替えることができます。 チャット ビューには、チャット履歴の保存と読み込み、チャットへのコンテキストの追加、応答を生成するためのさまざまなモデルの選択など、チャット セッションを管理するための機能も用意されています。

以下の手順に従って、演習のこのセクションを完了します。

1. チャット ビューを開いた状態から閉じた状態に切り替えるには、**[チャット]** ボタンを選択します (または **Ctrl + Alt + I** キーを押します)。

    [チャット] ボタン (ユーザー インターフェイスでは **[チャットの切り替え]** というラベルが付いています) は、Visual Studio Code ウィンドウの上部の検索テキストボックスのすぐ右側にあります。

1. チャット ビューを閉じた状態から開いた状態に切り替えるには、もう一度 **[チャット]** ボタンを選択します。

    チャット ビューの既定の場所は、Visual Studio Code ウィンドウの右側にあるセカンダリ サイド バーです。 **[ビューとその他のアクション]** ボタン (チャット ビューの上部メニューの 3 つのドット) を使用すると、チャット ビューを別の場所に移動したり、エディター タブでチャット ビューを開いたり、別のウィンドウで開いたりするためのオプションを含むコンテキスト メニューを開くことができます。

1. 少し時間を取って、Chat ビュー インターフェイスを確認しましょう。

    上から順に説明すると、チャット ビューには次のインターフェイス要素があります。

    - チャット ビュー ツール バー:チャット ビュー ツール バーは、チャット ビューの右上隅にあります。 ツール バーを使用すると、チャット履歴を管理し、新しいチャットを開始し、別の場所でチャット ビューを表示し、チャット ビューを非表示にすることができます。 ツール バーのボタン アイコンにマウス ポインターを置くと、説明が表示されます。

    - チャット応答領域:チャット応答領域は、GitHub Copilot による応答が表示されるチャット ビュー ツール バーの下の空間です。 応答には、コードの提案、説明、対話型の要素、プロンプトに関連するその他の情報が含まれます。

    - Copilot に質問:[Copilot に質問] テキスト ボックスは、プロンプトを入力する場所です。 [Copilot に質問] テキスト ボックスを使用すると、コードベースについて GitHub Copilot に質問し、コードの提案を依頼し、特定のタスクに関する支援を依頼することができます。

    - [コンテキストの追加] ボタン:[コンテキストの追加] ボタンは、チャット ビューの下部にあります。 このボタンを使用して、Chat セッションにコンテキストを追加するリソースを検索できます。 リソースには、内部プロジェクト ファイルから、組織外部の GitHub 上にあるパブリック リポジトリまで、あらゆるものが含まれます。

    - [ボイス チャットの開始] ボタン: チャット入力領域のマイク ボタンにより、GitHub Copilot とのボイス チャット セッションが開始されます。 ボイス チャットを使用するには、**VS Code Speech** 拡張機能をインストールする必要があります (VS Code Speech 拡張機能がインストールされていない場合、マイク アイコンは表示されません)。 音声セッションがアクティブな場合、音声入力が文字起こしされ、チャット プロンプトとして送信されます。

    - [チャット モード] メニュー:[チャット モード] ドロップダウン メニューは、[ボイス チャットの開始] ボタンの右側にあります。 具体的なニーズに応じて、さまざまなチャット モードを選択できます。

        - **質問**:このモードを使用して、コードベースについて GitHub Copilot に質問します。 質問モードを使用すると、コードの説明、変更の提案、コードベースに関する情報の提供を依頼できます。
        - **Plan**: このモードを使用して、コード変更を実装する前にワークスペースで計画します。 Plan モードを選択すると、GitHub Copilot によって、タスクをより小さなステップに分割した構造化された応答が提供されます。これは、コードを変更する前に全体的なアプローチを理解するのに役立ちます。 Plan モードは、通常、非常に複雑なタスク用に用意されています。
        - **エージェント**:このモードを使用して、GitHub Copilot をエージェントとして実行します。 GitHub Copilot を使用して、コマンドの実行、コードの実行、またはその他の各種タスクをワークスペース内で実行することができます。

    - [モデルの選択] メニュー:[モデルの選択] メニューは、[チャット モード] メニューの右側にあります。 このボタンを使用して、GitHub Copilot で応答を生成するために使用するモデルを選択できます。 既定のモデルは現在 GPT-4.1 ですが、より新しいモデルも使用できます。 モデルの選択は、GitHub Copilot サブスクリプション、GitHub Copilot の設定、リージョンで使用できるモデルに基づいて制限される場合があります。

    - [ツールの構成] ボタン: [ツールの構成] ボタンは、[モデルの選択] メニューの右側にあります。 このボタンを使用して、GitHub Copilot が Agent モードで使用できるツールを管理できます。 たとえば、[ツールの構成] メニューを使用して、GitHub Copilot をコードベース、ターミナル、またはタスクの実行時にエージェントがアクセスする必要があるその他のリソースに接続できます。

    - [送信] ボタン: [送信] ボタンは、[モデルの選択] メニューの右側にあります。 このボタンを使用して、プロンプトを GitHub Copilot に送信し、応答を受け取ることができます。 メニューには、プロンプトの送信方法に関するいくつかのオプションがあります。

    - [セッション ターゲットの設定] メニュー: [セッション ターゲットの設定] メニューは、チャット ビューの左下隅にあります。 このメニューを使用して、エージェントの実行場所を選択できます。 たとえば、VS Code エディターでローカルでエージェントを実行する、Copilot CLI を使用してバックグラウンドでエージェントを実行する、クラウドでリモートでエージェント実行する、または Anthropic の Claude などのサード パーティのエージェント ハーネスと SDK を使用することを選択できます。

    - [アクセス許可の設定] ボタン: [アクセス許可の設定] ボタンは、[セッションの委任] ボタンの右側にあります。 このボタンを使用して、現在のチャット セッションのアクセス許可を管理できます。 たとえば、このメニューを使用して、コードベース、ターミナル、またはその他のリソースへの GitHub Copilot のアクセスを許可または制限することができます。

1. [Copilot に質問] テキストボックスを使用して次のプロンプトを入力し、プロンプトを送信します。

    **C# の場合:**

    ```text
    Create a C# console app that prints Hello World to the console.
    ```

    **または Python の場合:**

    ```text
    Create a Python console app that prints Hello World to the console.
    ```

1. 少し時間を取って応答を確認します。

    GitHub Copilot の応答では、コンソール アプリ プロジェクトを作成するための手順は提供されますが、ユーザーに代わってタスクを完了することは提案されないことに注意してください。

1. コンソール アプリ プロジェクトを作成するには、チャット ビューの応答で提示される手順に従います。

    次に例を示します。

    Visual Studio Code の統合ターミナルを開き、統合ターミナルから次のコマンドを実行します。

    **C# の場合:**

    ```bash
    dotnet new console -n HelloWorldApp
    code HelloWorldApp
    ```

    **または Python の場合:**

    ```bash
    mkdir HelloWorldApp
    cd HelloWorldApp
    echo "print('Hello World')" > Program.py
    code .
    ```

### クイック チャット機能を確認する

クイック チャット ウィンドウは、GitHub Copilot と対話するための簡略化されたインターフェイスです。 コード エディターを離れることなく、簡単に質問したり、コードの提案を依頼したり、特定のタスクに関する支援を得たりすることができます。

以下の手順に従って、演習のこのセクションを完了します。

1. Visual Studio Code のチャット メニューを開きます。

    チャット メニューには、次のようなオプションが含まれています。

    - チャットを開く         **Ctrl + Alt + I** キー
    - インライン チャットを開く  **Ctrl + I** キー
    - クイック チャットを開く   **Ctrl + Shift + Alt + L** キー

1. チャット メニューで、**[クイック チャットを開く]** を選択します。

    既定では、クイック チャット ウィンドウは Visual Studio Code ウィンドウの上部中央に開きます。

1. クイック チャット ウィンドウには、チャット ビューで提供されるオプションのサブセットが表示されることに注意してください。

1. クイック チャット ウィンドウを使用して、次のプロンプトを送信します。

    ```text
    Tell me about the Program.cs file
    ```

1. 少し時間を取って応答を確認しましょう。

    Program.cs ファイルをエディターで開いていないか、クイック チャット コンテキストに追加していない限り、GitHub Copilot はファイルに関する特定の情報を提供できません。 ファイルをコンテキストに追加するように求められます。

1. Program.cs ファイルをクイック チャットのコンテキストに追加するには、Program.cs ファイルをエクスプローラー ビューからクイック チャット ウィンドウの一番上にドラッグ アンド ドロップします。

1. クイック チャット ウィンドウで、プロンプト テキスト ボックスのすぐ下に **Program.cs** が含まれるようになったことに注意してください。

    > **ヒント**: チャットにコンテキストを追加すると、GitHub Copilot がより関連性の高い応答を提供するのに役立ちます。 プロジェクト ファイルをチャット コンテキストに追加する場合、[コンテキストの追加] ボタンではなく、ドラッグ アンド ドロップ操作を使用する方が簡単な場合がよくあります。

1. クイック チャット ウィンドウの上部までスクロールし、同じプロンプトを再送信します。

    ```text
    Tell me about the Program.cs file
    ```

1. 新しい応答では、Program.cs ファイルの実行内容や実行方法など、Program.cs ファイルの詳細な説明が提供されます。

1. クイック チャット ウィンドウの右上にある **[チャット ビューで開く]** を選択します。

    クイック チャット ウィンドウが閉じて、クイック チャット ウィンドウに表示された応答を含むチャット ビューが開くことに注目してください。 チャット ビューに [クイック チャット] セッションが表示されない場合は、Copilot Chat メニューを使用してクイック チャット ウィンドウを開き、**[チャット ビューで開く]** を選択します。

    クイック チャット ウィンドウで開始されたチャット セッションを拡張および管理する必要がある場合は、チャット ビューに切り替えると便利です。

    > **ヒント**:クイック チャット ウィンドウは、簡単な質問や簡単なタスクに最適です。 ただし、さらに専用のチャット環境が必要な場合は、チャット ビューを使用してください。

### インライン チャット機能を確認する

インライン チャットを使用すると、チャット ビューに切り替えることなく、コード エディターで GitHub Copilot と直接対話できます。 **Ctrl + I** キーを押してカーソル位置でチャットプロンプトを開き、変更内容を説明すると、Copilot がその場で編集候補を提案します。

インライン チャット V2 エクスペリエンス (`inlineChat.enableV2` 設定で有効化) は、内部的にはチャット ビューの Agent モードと同じ編集ロジックを使用します。これは、同じコンテキストにアクセスでき、より高品質な編集が生成されることを意味します。 インライン チャット V2 では軽量モードもサポートされています。`inlineChat.hideOnRequest` 設定が有効な場合、プロンプトを送信するとすぐにインライン チャット入力が非表示になり、変更は、**[保持]** および **[元に戻す]** コントロールがある標準のチャット編集オーバーレイに表示されます。

アクティブなエージェント セッションにファイルが属している場合、**Ctrl + I** キーを押すと、通常のインライン チャットではなく、チャット ビューで [チャットで質問する] が開きます。 これにより、プロンプトが既存のセッションにルーティングされ、会話全体のコンテキストを使用できるようになります。 `inlineChat.askInChat` を `false` に設定すると、この動作を無効にできます。

インライン チャットを開かずに、既存のチャット セッションにコードの選択またはファイルを追加することもできます。 エディターで選択したコードを右クリックし、**[選択をチャットに追加]** を選択するか、エクスプローラーでファイルを右クリックし、**[ファイルをチャットに追加]** を選択します。 これにより、コードまたはファイルがチャット ビューのコンテキストとして添付されるため、それを参照する質問を行ったり、編集を要求したりすることができます。

### チャット ビューの Ask モードと Agent モードを比較する

チャット ビューには、3 つのモード (**Ask**、**Plan**、**Agent**) があります。 Ask モードは、質問およびコード候補の生成向けに設計されています。 Agent モードは、Copilot がワークスペースでの検索、ファイルの編集、ターミナル コマンドの実行、ツールの使用を行うことができる自律コーディング タスク向けに設計されています。 Plan モードは、複雑なタスクを小さなステップに分割して計画するために設計されています。

> **注**: Edit モードは VS Code 1.110 の時点で非推奨となり、今後のリリースでは削除される予定です。 Agent モードは、Edit モードの機能のスーパーセットを提供します。 以下の手順では、代わりに Ask モードと Agent モードを使用します。

以下の手順に従って、演習のこのセクションを完了します。

1. コード エディターで Program.cs ファイルを開き、既存のコードを次のコード スニペットに置き換えます。

    ```csharp

    using System;
    
    namespace HelloWorldApp;
    
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World");
        }
    }

    ```

1. チャット ビューが開かれており、**[Ask]** エージェントが選択されていることを確認します。

1. 次のコードを選択します。

    ```csharp

    static void Main(string[] args)
    {
        Console.WriteLine("Hello World");
    }

    ```

    チャット ビューのコンテキストが更新され、Program.cs ファイル内の選択したコード行が指定されていることに注目してください。

1. チャット ビューで、次のプロンプトを入力します。

    ```text

    Refactor the selected code to display "Generate equations for addition and subtraction:"

    ```

1. 少し時間を取って、チャット ビューに表示された応答を確認しましょう。

    応答にコード スニペットが含まれていることに注意してください。 コードの上にマウス ポインターを置くと、チャット ビューで、コードの右上隅に、次のオプションを提供するボタンが表示されます。

    - **Program.cs に適用**:[Program.cs に適用] オプションを使用して、提案されたコードの更新を Program.cs ファイルに適用します。
    - **カーソル位置に挿入**:[カーソル位置に挿入] オプションを使用して、提案されたコードの更新をエディターの現在のカーソル位置に挿入します。
    - **コピー**:[コピー] オプションを使用して、提案されたコードの更新をクリップボードにコピーします。

    これらのオプションのいずれかを使用して、提案されたコードの更新を適用することもできますが、この演習では、Agent モードを使用して更新を直接適用します。

1. チャット ビューで、[エージェントの設定] ドロップダウンを開き、**[エージェント]** を選択します。

1. 次のプロンプトを送信します。

    ```text

    Refactor the selected code to display "Generate equations for addition and subtraction:"

    ```

1. 少し時間を取って、コード エディターで提案された更新を確認しましょう。

    次のことに注意してください。

    - Agent モードでは、Copilot によって、編集がファイルに直接適用されます。 コード エディターには、GitHub pull request で使用される Diff ビューと同様に、変更を示す "Diff スタイル" ビューが表示されます。**
    - コード エディターには、コードに加えられた変更を適用するか拒否するために使用できる **[保持する]** ボタンと **[元に戻す]** ボタンが表示されます。
    - コード エディターには、編集候補を管理するために使用できる追加のボタンが表示されます。

    エディター タブに表示される編集コントロールに加えて、チャット ビューには、すべての編集を適用するために使用できる **[保持]** ボタン、編集を取り消す **[元に戻す]** ボタン、更新候補の簡潔な説明が表示されます。

1. チャット ビューで **[保持]** を選択し、提案されたコードの更新をすべて適用します。

> **注**: Agent モードでは、Copilot はターミナル コマンドを実行したり、ワークスペースでコンテキストを検索したり、他のツールを自律的に使用したりすることもできます。 既定では、Copilot はターミナル コマンドを実行する前に承認を求めます。 GitHub Copilot リソースを節約するために、この演習では、ファイルの編集のみを要求する単純なプロンプトを使用します。

### コード補完と次の編集候補を調べる

GitHub Copilot により、入力時に次の 2 種類のインライン候補が提示されます。

- **ゴースト テキスト候補 (コード補完)**: 現在のカーソル位置に、現在の行または新しいコードのブロックの入力候補を示す淡色表示のテキストが表示されます。
- **次の編集候補 (NES)**: Copilot は、既に行っている変更に基づいて、次の編集の場所と内容の両方を予測します。 余白に、次の編集候補を配置する場所を示す矢印が表示されます。

どちらの機能も既定で有効になっており、ステータス バーの GitHub Copilot 状態メニューを使用して構成できます。

#### ゴースト テキストによるコード補完を調べる

以下の手順に従って、演習のこのセクションを完了します。

1. コード エディターで Program.cs ファイルを開き、カーソルを Console.WriteLine ステートメントの末尾に置きます。

1. コード補完の候補を生成するには、**Enter** キーを押します。

    しばらくすると、GitHub Copilot により、エディター内のコードのコンテキストに基づいてコード補完の候補 (ゴースト テキスト) が生成されます。

1. コード補完の提案を受け入れるには、**Tab** キーを押します。

    エディター内のコードが更新され、提案されたコード行が含まれます。

    コード補完の提案を受け入れると、GitHub Copilot から追加のコード行が提案されることがあります。 このような場合は、**Tab** キーを押して提案を受け入れるか、**Esc** キーを押して提案を拒否するか、独自のコードを入力して提案をオーバーライドできます。

#### 次の編集候補を調べる (NES)

次の編集候補は、既に行った変更に基づいて次のコード編集を予測します。 たとえば、ある行で変数の名前を変更すると、NES によって、他の行の同じ変数名を更新するように提案されます。

以下の手順に従って、演習のこのセクションを完了します。

1. Program.cs ファイルがコード エディターで開かれていることを確認します。

1. 既存の Program クラスを次のコード スニペットに置き換えます。

    ```csharp

    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Generate equations for addition and subtraction:");
            for (int i = 0; i < 5; i++)
            {
                int num1 = new Random().Next(1, 100);
                int num2 = new Random().Next(1, 100);
                Console.WriteLine($"{num1} + {num2} = {num1 + num2}");
                Console.WriteLine($"{num1} - {num2} = {num1 - num2}");
            }
    
        }
    }

    ```

1. コード エディターで、変数名 **num1** を選択します。

1. 変数名を変更するには、「**position1**」と入力します

1. 次の編集候補を探します。

    Main メソッドの他のコード行で、変数名 **num1** を **position1** に更新するための次の編集候補が表示されます。 変数名 **num2** を **position2** に変更することを提示する次の編集候補が表示される場合もあります。 候補が一度にすべての行に表示されない場合があります。 代わりに、コードに変更を加えるたびに 1 つずつ表示される場合があります。

1. エディターの左側の余白で矢印インジケーターを探します。

1. 次の編集候補に関するオプションの一覧を表示するには、矢印の上にマウス ポインターを置きます。

    次の候補の承諾または拒否を含むオプションが表示されます。

1. **Tab** キーを押して、編集候補の "移動または承諾" を行います。

    NES は、必要な関連する変更を予測することで、コーディングの流れを維持するのに役立ちます。 変更のスコープに応じて、候補は 1 つの記号、行全体、または複数行に及ぶ場合があります。

### スマート アクションにアクセスする

スマート アクションとは、Copilot のコンテキスト メニューから使用できる一連の定義済みアクションです。 スマート アクションを使用すると、プロンプトを入力することなく、Visual Studio Code で一般的なタスクをすばやく実行できます。

以下の手順に従って、演習のこのセクションを完了します。

1. Program.cs ファイルがコード エディターで開かれていることを確認します。

1. コード エディターで Main メソッドを選択し、選択したコードを右クリックして、**[説明]** を選択します。

1. 少し時間を取って、スマート アクションの結果を検討してみましょう。

    [説明] スマート アクションにより、コードの選択に基づいてプロンプトが作成され、そのプロンプトがチャット ビューに送信されることに注目してください。

    説明には、選択したコードの詳細な説明が含まれ、更新の提案も含まれる場合があります。

    たとえば、説明には、ループの各反復で新しいインスタンスを作成するのではなく、使用する `Random` クラスの使用を更新するという提案が含まれる場合があります。

    ```csharp

    // ...existing code...
    Random random = new Random();
    for (int i = 0; i < 5; i++)
    {
        int position1 = random.Next(1, 100);
        int position2 = random.Next(1, 100);
        // ...existing code...
    }

    ```

    [説明] スマート アクションは、コード レビュー ツールとして設計されていません。 候補に基づいて更新を行うことができますが、別のオプションがあります。 [レビュー] スマート アクションです。

1. 選択したコードをもう一度右クリックし、**[レビュー]** を選択します。

    [レビュー] スマート アクションを使用すると、コードの品質、セキュリティ、パフォーマンス、ベスト プラクティスへの準拠を改善するための候補など、コードを改善するための候補を取得できます。

    上記の問題が [説明] スマート アクションで検出されなかったとしても、[レビュー] スマート アクションで検出できます。

1. [レビュー] スマート アクションによって提供された更新候補を確認します。

    [レビュー] スマート アクションにより、ループの反復間で再利用される `Random` クラスの単一のインスタンスが推奨されます。これは、.NET で乱数を生成するためのベスト プラクティスです。 また、現在の名前は現在のコンテキストではわかりにくい可能性があるため、`position1` と `position2` に置き換わる改善された変数名が提案される場合もあります。

1. 適用オプションを選択して、変更候補を実装します。

    最初の候補には **[適用して次に移動]** ボタンを使用し、保持したい最後の候補には **[適用]** ボタンを使用します。 また、候補を適用しない場合は、それを拒否するオプションもあります。
